📊 FUTURE_DS_02 – Social Media Campaign Performance Tracker

This repository contains Task 2 of my Data Science & Analytics Internship at Future Interns. The project focuses on analyzing and visualizing social media advertising performance using an interactive Power BI dashboard.

🔹 Project Overview

The goal of this project is to evaluate and compare the performance of social media campaigns across Facebook and Instagram by analyzing key marketing and engagement metrics.

The dashboard helps in:

Understanding campaign effectiveness

Measuring return on investment (ROI)

Tracking user engagement trends

📂 Dataset

File Name: Social_Media_Advertising.csv

Source: Kaggle / Internship Dataset

Columns Included:

Campaign Name

Platform

Impressions

Clicks

Spend

Revenue

Likes

Comments

Shares

📈 Key Metrics Calculated

CTR (%) = (Clicks ÷ Impressions) × 100

CPC = Spend ÷ Clicks

ROI (%) = ((Revenue − Spend) ÷ Spend) × 100

📊 Dashboard Features

KPI Cards:

Click Through Rate (CTR)

Return on Investment (ROI)

Total Spend

Total Revenue

Visualizations:

Bar Chart: ROI by Campaign

Pie Chart: Spend Distribution by Platform

Engagement Metrics: Likes, Comments, Shares

Trend Analysis: Daily Spend vs Revenue

🔧 Tools & Technologies Used

Power BI

Excel / Google Sheets

GitHub

🧠 Key Insights

Instagram campaigns achieved ~20% higher CTR compared to Facebook.

“New Year Blast” campaign delivered the highest ROI (230%).

“Summer Sale” campaign generated the highest engagement, with over 2,500 likes.
